# 프로필 카드 (Profile Card)

3주차 실습으로 만든 나만의 반응형 프로필 카드입니다.

## 소개

Gemini로 코드를 생성하고, 여러 단계를 거쳐 직접 수정하며 완성한 개인 프로필 카드입니다.

## 사용 기술

- HTML / CSS / JavaScript

## 배포 링크

- 소개부, 링크 버튼, 다크모드 기능을 포함한 첫 배포입니다.

## 담긴 내용

- 프로필 사진, 이름, 소개 문구
- SNS 링크
- 링크 버튼 섹션
- 다크모드 전환 기능
