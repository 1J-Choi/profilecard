# CSS — 스타일과 반응형 설명 (초보자용)

이 문서는 `style.css` 파일의 주요 스타일 규칙과 변수, 반응형 처리, 다크 모드 등 핵심 개념을 설명합니다.

## CSS의 목적
- HTML은 구조(내용)를 담당하고, CSS는 그 구조를 '어떻게 보일지' 결정합니다. 색상, 여백, 폰트, 크기, 배치, 애니메이션 등을 담당합니다.

## 주요 섹션 설명

- `:root{ --변수명: 값; }` — CSS 변수(커스텀 프로퍼티)를 정의합니다. 예: `--primary`는 주요 파란색을 한 곳에서 관리하기 위해 사용합니다.
- `.wrap` — 카드 전체를 화면 가운데 정렬하는 컨테이너입니다.
- `.card` — 프로필 카드의 배경, 테두리, 그림자, 반응형 패딩을 정의합니다. `border-radius`로 둥근 모서리를 만듭니다.
- `.avatar img` — 원형 프로필을 만들기 위해 `border-radius:50%`와 `object-fit:cover`를 사용합니다. `object-fit`은 이미지의 비율을 유지하면서 잘라내서 채웁니다.
- `.social .icon` — 소셜 아이콘(작은 버튼) 스타일입니다. SVG 색상은 `fill: var(--primary)`로 변수에 의해 제어됩니다.
- `.links` 및 `.link-btn` — 프로필 아래의 링크 버튼들을 스타일링합니다. 현재는 파란색 그라데이션 배경과 약한 그림자, 약간의 호버(올라오는) 효과가 적용되어 있습니다.

## 반응형 (responsive)
- `@media (max-width:420px){ ... }` 같은 규칙은 작은 화면(모바일)에서 글자 크기, 이미지 크기, 패딩을 줄여서 레이아웃이 깨지지 않게 합니다.

## 다크 모드
- `body[data-theme="dark"]{ ... }` 규칙은 다크 테마일 때 CSS 변수를 재정의합니다. 자바스크립트에서 `data-theme` 속성을 바꿔 다크/라이트를 전환합니다.

## 가독성 및 유지보수 팁
- 색상이나 주요 값은 `:root`의 변수에서 관리하면 전체 테마 변경이 쉬워집니다.
- 스타일을 바꿀 때는 먼저 변수값을 수정해보고, 필요하면 특정 클래스에만 오버라이드하세요.
